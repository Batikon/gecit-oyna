# Geçit

[Tarayıcıda oyna](https://batikon.github.io/gecit-oyna/) · [Telefonla okutmak için QR](https://batikon.github.io/gecit-oyna/qr.png)

Telefonu yatay tut ve **Oyuna gir** düğmesine dokun. Sol başparmağınla şövalyeyi yürüt, sağdaki **VUR** ile saldır ve **KALKAN** ile savun. Merkez sancağı takımın elinde tuttuğunda, güvenli olduğu sürece öldükten sonra oradan yeniden doğarsın.

Aynı v0.3.1 sürümünü Android telefona kurup çevrimdışı oynayabilir veya kısa maç kaydını izleyebilirsin. [Android ARM64 APK](https://github.com/Batikon/gecit-oyna/releases/download/v0.3.1/Gecit-v0.3.1-Android-arm64.apk) · [12 saniyelik maç kaydı](https://batikon.github.io/gecit-oyna/oynanis.mp4)
